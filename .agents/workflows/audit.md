# Audit Workflow

## Process
1. Scan repository
2. Understand architecture
3. Build project
4. Run existing tests
5. Inspect logs
6. Check TODO/FIXME
7. Check error handling
8. Check network failure handling
9. Check resource management
10. Check memory leaks
11. Check threading/concurrency
12. Check security
13. Check file transfer reliability
14. Check screen streaming stability
15. Check database consistency
16. Check UI/UX issues
17. Produce audit report

## Output
Create an audit report in `docs/audit/` containing:
- `architecture.md`
- `bugs.md`
- `security.md`
- `performance.md`
- `feature-gaps.md`
